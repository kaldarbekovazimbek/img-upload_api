# 📌 Техническое задание

## Image Upload API (Laravel)

---

## 🎯 Цель проекта

Разработать REST API для загрузки и управления изображениями пользователей с авторизацией и ограничениями по безопасности и ресурсам.

---

# 🔐 1. Авторизация

Реализовать механизм авторизации пользователей.

### Требования:

* Использовать токен-авторизацию (например, Laravel Sanctum или JWT).
* Все API маршруты должны быть **закрытыми** (доступ только для авторизованных пользователей).
* Пользователь может работать **только со своими изображениями**.

---

# 📤 2. Загрузка изображения

### Endpoint:

```
POST /api/images
```

### Требования:

* Доступ только для авторизованных пользователей.
* Поддерживаемые форматы:

    * `image/png`
    * `image/jpeg`
* Максимальный размер файла: **5 MB**
* Валидация обязательна.

### Ответ:

```json
{
  "id": 1,
  "filename": "image.webp",
  "size": 123456,
  "url": "https://domain.com/api/images/1"
}
```

---

# 📄 3. Получение списка изображений

### Endpoint:

```
GET /api/images
```

### Требования:

* Возвращает только изображения текущего пользователя.
* Поддержка пагинации.
* Сортировка по дате загрузки (по убыванию).

---

# 🖼 4. Получение изображения

### Endpoint:

```
GET /api/images/{id}
```

### Требования:

* Доступ только владельцу изображения.
* Возвращает изображение как файл (stream response).
* При попытке доступа к чужому изображению — 403.

---

# 🗑 5. Удаление изображения

### Endpoint:

```
DELETE /api/images/{id}
```

### Требования:

* Удалять может только владелец.
* Удаляется запись в БД.
* Файл удаляется с диска (если не используется другими пользователями).

---

# 📦 Ограничения

| Ограничение         | Значение        |
| ------------------- | --------------- |
| Формат              | PNG, JPEG       |
| Максимальный размер | 5 MB            |
| Доступ              | Только владелец |

# ⭐ Дополнительные требования (будет плюсом)

## 1️⃣ Высокая нагрузка (100 000+ загрузок в день)

Рекомендуется:

* Использовать очереди (Queue) для обработки изображений.
* Асинхронное сжатие.
* Использование CDN или S3-хранилища.
* Индексация БД.

---

## 2️⃣ Сжатие изображений

* Оптимизация размера без значимой потери качества.
* Разрешается изменение формата (например, конвертация в WebP).
* Использовать библиотеку для обработки изображений (например, Intervention Image).

---

## 3️⃣ Избежание дублирования

Требуется:

* Генерировать hash (например, SHA-256) от содержимого файла.
* Если файл с таким hash уже существует:

    * Не сохранять дубликат физически.
    * Связывать пользователя с существующим файлом.
